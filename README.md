# Capstone 2
## Sales Analysis of EmporiUm
### Overview
This capstone analysis sales the sales performance for the company Emporium, Emporium is a retail chain. My task was to conduct a sales analysis of the Colorado and Maine territories.
The outcome of this analysis was to find the top performing categories and stores, trends in revenue, differences in territory performances and what Emporium should do moving forward.
This project uses Python, pandas, NumPy, and Matplotlib to clean, aggregate, and visualize the data.

This project uses:
Python 3.10+
pandas — data cleaning & aggregation
NumPy — numerical operations
Matplotlib — data visualization
Jupyter Notebook — analysis environment
